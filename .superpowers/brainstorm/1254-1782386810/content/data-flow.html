数据流与通信协议

Streamlit ↔ Vue ↔ OnlyOffice 三层通信

完整数据流
① 用户上传文件 (Streamlit)
st.file_uploader → 读取 bytes → base64 编码 → 传入 iframe
↓
② Vue 接收 (useStreamlitBridge)
解析 URL params / postMessage → 提取 base64 + filename + fieldList
↓
③ 加载到 OnlyOffice
OnlyOffice API: docEditor.openDocument(base64) → 原生渲染
↓
④ 用户编辑 + 插入字段 (循环)
编辑 → OnlyOffice 内部处理 | 点击字段面板 → postMessage → OnlyOffice API 插入文本
↓
⑤ 用户点下载
OnlyOffice API: docEditor.save() → 拿到 base64 → 传回 Streamlit → st.download_button

通信接口

方向 通道 数据
Streamlit → Vue iframe URL params 或 JS bridge { fileBase64, fileName, fieldList }
Vue → OnlyOffice postMessage (OnlyOffice API) openDocument / insertText / save
OnlyOffice → Vue postMessage 回调 { status, data (base64) }
Vue → Streamlit JS bridge (回传) { fileBase64, fileName }
