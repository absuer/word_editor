整体架构

Vue 编辑器嵌入 Streamlit 的完整数据流

架构总览
🐍 Streamlit (app.py)
文件上传 · Session 管理 · 下载触发
↔
📦 文件桥接层
base64 编码/解码 · JS ↔ Python 通信
↓
🟢 Vue 3 编辑器 (独立前端项目)
📝 WordEditor.vue
TipTap 编辑器
加载 · 编辑 · 格式化 · 下载
📊 ExcelEditor.vue
Handsontable
加载 · 编辑 · 下载
📥 DocxIO.ts
mammoth.js → docx 读取
docx.js → docx 生成
📤 FileBridge.js
接收 base64 → 解析 → 编辑 → 回传 base64

关键设计点

📁 文件流转

Streamlit 读文件 → base64 → JS bridge → Vue 解析编辑 → base64 → Streamlit 下载

🔄 双格式路由

按 .docx / .xlsx 扩展名自动切换 Word / Excel 编辑器

📦 部署方式

Vue build 为静态文件，Streamlit serve 为静态资源，通过 iframe 嵌入

🧩 协议友好

TipTap (MIT) + Handsontable (free) + mammoth.js (BSD) + docx.js (MIT)
