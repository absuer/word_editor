关键变化

✅ 优势

  • Word/Excel 100% 还原，与桌面 Office 完全一致
  • ranuts/document 已验证可行，有参考实现
  • 编辑器功能远超 A 级，后续扩展空间大

⚠️ 代价

  • 体积约 30MB（WebAssembly），首屏加载慢
  • AGPL-3.0 协议（需开源衍生代码）
  • OnlyOffice 编辑器在 iframe 内，字段面板无法直接控制编辑器
  • 插入字段需通过 OnlyOffice API postMessage 通信

⚠️ 重要：字段插入的可行性

OnlyOffice 编辑器运行在独立的 iframe 中。要实现"点击字段 → 插入到光标位置"：

  • 必须通过 OnlyOffice JS API → postMessage 通信
  • 可以调用 docEditor.insertText() 或操作 document 插入文本
  • ranuts/document 也是纯前端模式，同样的通信机制，技术上可行
